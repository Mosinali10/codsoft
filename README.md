# 🚀 CodSoft Internship Projects

A collection of diverse programming projects developed during the CodSoft internship program, showcasing skills in Python, C, machine learning, and algorithm design.

## 📋 Overview

This repository contains four distinct projects demonstrating various programming concepts, from machine learning and data science to game development and interactive applications.

## 🗂️ Projects

### 1. 🎬 [Movie Recommendation System](./movie-recommendation-system/)

A content-based movie recommendation engine using machine learning.

**Technologies**: Python, Pandas, NumPy, scikit-learn  
**Key Features**:
- TF-IDF vectorization
- Cosine similarity algorithm
- 4,803 movie dataset
- Content-based filtering

[View Project →](./movie-recommendation-system/)

---

### 2. 🌡️ [Temperature Converter](./celsius-to-fahrenheit-converter/)

An interactive command-line tool for temperature conversion.

**Technologies**: Python  
**Key Features**:
- Celsius ↔ Fahrenheit conversion
- Input validation
- User-friendly interface
- Bonus: Task Manager application

[View Project →](./celsius-to-fahrenheit-converter/)

---

### 3. ⭕ [Tic Tac Toe with AI](./tic-tac-toe-game/)

An unbeatable Tic Tac Toe game with AI opponent.

**Technologies**: C, Minimax Algorithm  
**Key Features**:
- Minimax algorithm implementation
- Optimal AI decision-making
- Win/draw detection
- Clean ASCII board display

[View Project →](./tic-tac-toe-game/)

## 🚀 Quick Start

### Python Projects

1. **Install Python dependencies**:
   ```bash
   cd movie-recommendation-system
   pip install -r requirements.txt
   ```

2. **Run the project**:
   ```bash
   python celsius_to_fahrenheit.py
   ```

### C Projects

1. **Compile**:
   ```bash
   gcc chatbot.c -o chatbot -lm
   gcc tic_tac_toe.c -o tic_tac_toe
   ```

2. **Run**:
   ```bash
   ./chatbot
   ./tic_tac_toe
   ```
