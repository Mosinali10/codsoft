# Temperature Converter (Streamlit)

## Project Description

This project is a Streamlit web application for converting temperatures between Celsius and Fahrenheit. It provides two dedicated conversion panels (C → F and F → C) with a clean UI and a small reference table for common values.

## Features

- Celsius to Fahrenheit conversion
- Fahrenheit to Celsius conversion
- Reference table for common temperatures
- Runs as a lightweight local web app (no backend)

## Technology Stack

- Python
- Streamlit

## How to Run the Project

From the repository root:

```bash
cd projects/temperature-converter-streamlit
pip install -r requirements.txt
streamlit run app.py
```

Streamlit will print a local URL (typically `http://localhost:8501`).
