About the AI

This AI uses the Minimax Algorithm to make optimal moves. It evaluates all possible game states and chooses the best move. The AI is unbeatable - the best you can do is draw!

How Minimax Works:

  • Evaluates all possible moves recursively
  • Assumes both players play optimally
  • Assigns scores: +1 (AI wins), -1 (Player wins), 0 (Draw)
  • Chooses moves that maximize AI's score
