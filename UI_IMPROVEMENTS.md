## 📊 Design System

### Color Palette
- **Primary**: #667eea (Purple-Blue)
- **Secondary**: #764ba2 (Purple)
- **Success**: #4CAF50 (Green)
- **Warning**: #FF9800 (Orange)
- **Error**: #f44336 (Red)
- **Background**: White with gradients

### Typography
- **Font Family**: Poppins
- **Headings**: 700 weight
- **Body**: 400 weight
- **Labels**: 600 weight

### Spacing
- **Card Padding**: 3rem
- **Section Margin**: 2rem
- **Element Gap**: 1rem

### Effects
- **Shadows**: 0 20px 60px rgba(0,0,0,0.3)
- **Border Radius**: 15-20px
- **Transitions**: 0.3s ease
- **Hover Effects**: translateY(-2px)
